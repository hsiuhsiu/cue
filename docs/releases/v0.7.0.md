# Cue 0.7.0 — Instant calculator / 即時計算

## English

Cue 0.7.0 adds an offline calculator directly to the launcher, including powers.

- **Answers while typing:** enter `1+2*3`, `(12+8)/4`, or `2^10`. A complete
  supported expression shows its answer first, with matching apps and commands
  below it and at most nine results in total. There is no separate calculator
  page or setting.
- **Copy with the keyboard:** select the answer and press **Return**, or use
  **Command+1**, to copy only its numeric value and close Cue. Paste with
  **Command+V** in the destination app. Typing alone does not change the
  clipboard, and Cue does not paste automatically.
- **Powers and clear precision:** use `^` or adjacent `**`, including `2^-3`
  and `9^0.5`. Powers associate right to left: `2^3^2` is `512`. Parentheses
  distinguish `(-2)^2` (`4`) from `(-2^2)` (`-4`). Exact answers show **`=`**;
  approximate answers show **`≈`**, with up to 16 significant digits.
  Fractional powers always show `≈`.
- **Local and bounded:** decimals, parentheses, scientific notation and basic
  arithmetic are supported; expressions must start with a digit or `(` and
  contain an operator. A plain number remains an ordinary search. Incomplete,
  undefined or out-of-range expressions produce no calculator answer. Inputs
  are limited to 512 UTF-8 bytes, 256 tokens and 32 nested levels; exponents
  are limited to −10,000 through 10,000. Calculation needs no network or extra
  permission and works with both Cue networking and browser search disabled.
  Expressions and answers are excluded from search-learning history; copied
  answers follow Clipboard History's normal recording settings.

See the [calculator guide](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/calculator.md)
for syntax, limits and interaction with app and Google search.

### Install or upgrade

[Download Cue 0.7.0](https://github.com/hsiuhsiu/cue/releases/download/v0.7.0/Cue-0.7.0-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v0.7.0/SHA256SUMS.txt)

With Cue network access enabled, choose **Check for Updates…**, then **Install
and Relaunch**. Or quit Cue, open the DMG, and drag **Cue.app** into
**Applications**, replacing the old copy. Open the installed app and press
**Option+Space**. Existing settings, clipboard history and search learning are
preserved. Updating requires a writable installed location, not the read-only
DMG. Automatic downloads and unattended installation remain disabled.

To build your own copy, install full **Xcode with Swift 6 or later**, open it once
to complete its license and setup, quit Cue, then run:

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

The optimized app stays installed at `~/Applications/Cue.app`. The first build
downloads the pinned Sparkle dependency. To update that source build, quit Cue,
run `git pull --ff-only` and `./scripts/install-app.sh` in the same repository,
then reopen the installed app. Source builds default to Cue-owned networking
and automatic update checks **off**; official DMGs default to **on**. Explicit
saved choices are preserved. Browser search has its own enabled-by-default
switch in both builds. Installing an update offered by Cue replaces a source
build with the published app. See the
[source guide](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/building.md) and
[network policy](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/network-policy.md).

### Installation and testing limits

The app is ad hoc-signed, **without Developer ID signing or Apple notarization**.
If macOS blocks first launch, follow the app-specific
[installation instructions](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/installation.md).
Chinese text replacement still needs Accessibility permission for the installed
copy; rebuilding or updating can invalidate an older grant.

The universal app targets **macOS 14+**, with Apple silicon and Intel binaries.
Runtime verification is on **Apple silicon / macOS 27.0 / Xcode 27**. Intel,
other macOS versions, first installation on another Mac, and a full public
update installation remain unverified. System-action checks use substitutes;
actual sleep, lock, display-off and logout/reboot startup cycles have not been
verified for this release.

## 正體中文

Cue 0.7.0 將離線計算機直接加入主搜尋，並支援次方。

- **打字即顯示答案：**輸入 `1+2*3`、`(12+8)/4` 或 `2^10`。完整且支援的
  算式會把答案放在第一列，符合的 App 與指令仍列在下方，合計最多九筆。
  不需要另外進入計算機頁面，也沒有額外設定。
- **用鍵盤拷貝：**選取答案後按 **Return**，或直接按 **Command+1**，只拷貝
  數值並收起 Cue，再到目標 App 按 **Command+V** 貼上。單純打字不會修改
  剪貼簿，Cue 也不會自動貼上。
- **次方與明確精度：**可用 `^` 或相鄰的 `**`，包含 `2^-3` 與 `9^0.5`。
  連續次方由右向左算，`2^3^2` 為 `512`；括號可區分 `(-2)^2`（`4`）與
  `(-2^2)`（`-4`）。精確答案顯示 **`=`**，近似答案顯示 **`≈`**，最多保留
  16 位有效數字；小數次方一律標示 `≈`。
- **離線且限制工作量：**支援小數、括號、科學記號與基本四則運算；算式必須
  以數字或 `(` 開頭並含運算符號，單純數字仍視為一般搜尋。不完整、未定義
  或超出範圍時不顯示計算答案。輸入最多 512 個 UTF-8 位元組、256 個語法
  項目及 32 層巢狀深度，指數限制在 −10,000 到 10,000。計算不需網路或額外
  權限，Cue 自行連網與瀏覽器搜尋都關閉時仍可使用。算式及答案不會加入
  搜尋學習記錄；已拷貝的答案依剪貼簿記錄原有設定處理。

語法、限制及與 App／Google 搜尋的互動方式，詳見
[計算機說明](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/calculator.md)。

### 安裝或升級

[下載 Cue 0.7.0](https://github.com/hsiuhsiu/cue/releases/download/v0.7.0/Cue-0.7.0-universal.dmg) · [檢查碼](https://github.com/hsiuhsiu/cue/releases/download/v0.7.0/SHA256SUMS.txt)

允許 Cue 使用網路後，選擇**檢查更新⋯**，再依提示安裝並重新啟動（**Install
and Relaunch**）；或先結束 Cue，開啟 DMG，將 **Cue.app** 拖進**應用程式**取代
舊版，再開啟安裝好的 App，按 **Option+Space**。原有設定、剪貼簿記錄與搜尋
學習資料都會保留。更新需要可寫入的安裝位置，不能直接在唯讀 DMG 中執行；
自動下載及無人操作安裝仍維持停用。

自行編譯需要內含 **Swift 6 以上的完整 Xcode**，先開啟完成授權與設定、結束
Cue，再執行：

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

最佳化 App 會固定安裝至 `~/Applications/Cue.app`。首次建置下載固定版本的
Sparkle；更新自行建置版時，先結束 Cue，在同一份儲存庫執行 `git pull --ff-only`
與 `./scripts/install-app.sh`，再重新開啟已安裝的 App。自行建置版預設**關閉**
Cue 自行連網與自動檢查更新，正式 DMG 預設**開啟**；明確儲存的選擇會保留。
兩種版本的瀏覽器搜尋皆有獨立、預設開啟的開關。若從 Cue 安裝提供的更新，
會將自行建置版換成發布版。詳見
[原始碼指引](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/building.md)與
[網路政策](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/network-policy.md)。

### 安裝與驗證限制

App 使用 ad hoc 簽章，**沒有 Developer ID 簽署，也未經 Apple 公證**。若 macOS
阻擋首次開啟，請依針對 Cue 的
[安裝說明](https://github.com/hsiuhsiu/cue/blob/v0.7.0/docs/installation.md)操作。
簡繁文字取代仍需要為目前安裝的 Cue 開啟輔助使用權限；重新建置或更新可能
使舊授權失效。

通用版目標為 **macOS 14+**，包含 Apple silicon 與 Intel 執行檔。實際執行驗證
環境為 **Apple silicon／macOS 27.0／Xcode 27**；Intel、其他 macOS 版本、另一台
Mac 的首次安裝，以及完整的公開更新安裝流程，仍未驗證。系統指令檢查使用
替代動作；本次發布尚未實際驗證睡眠、鎖定、關閉顯示器及登出／重開機後啟動
的完整循環。
