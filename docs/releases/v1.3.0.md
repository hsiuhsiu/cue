# Cue 1.3.0 — Faster everyday actions / 更順手的日常操作

## English

This release improves learned app ranking, pasting from clipboard history, repeated window layouts, and Chinese filename input. Source installations can now keep a fixed local signing identity across updates.

[Download Cue 1.3.0](https://github.com/hsiuhsiu/cue/releases/download/v1.3.0/Cue-1.3.0-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v1.3.0/SHA256SUMS.txt)

### Changes

- **Ranking learns your exact query:** repeatedly choosing Home Assistant for `HA` now moves it ahead of incidental partial matches. Existing learning is reused; explicit aliases and exact full names remain first. General popularity still stays within its match category.
- **Paste from Clipboard History:** **Return** and **Command+1–9** paste the selected record into the original app. **Copy / Command+Return** keeps the copy-only action. Pasting needs Accessibility permission; Cue offers a setup button when it is missing. It validates the original app, window, input element and copied item before pasting, and cancels stale handoffs.
- **Reliable consecutive window layouts:** fixes rapid **Option+M → custom number** operations that could leave a partially moved window or an open panel. Cue keeps the source app in front and verifies the resulting frame, with at most one geometry correction when the old position limits resizing. Window controls remain enabled by default; saved off choices and panel-dismiss preferences are preserved. Use the menu-bar **Window Settings…** entry for shortcuts, presets and permission status.
- **Chinese input updates search immediately:** filename searches such as `f 身` follow the visible text during input-method composition. Return and arrow keys remain with the input method until text is committed. Late results do not overwrite a newer query or disturb composition. The native editor also avoids unnecessary layout work on long input.
- **Fixed local signing for source builds:** run `./scripts/setup-local-signing.sh` once to create a free signing identity in this Mac's Keychain. Later builds and clones under the same account reuse it automatically. The first switch needs one new Accessibility grant; subsequent source updates keep the same app identity. Missing configured keys, different signers and damaged bundles stop the build or installation instead of silently changing identity. No runtime work or new dependency is added.
- **Link validation:** rejects percent-encoded control characters in URL hostnames consistently on newer macOS versions.
- **Currency cache:** finishes setting private file permissions before atomically publishing refreshed rates, removing a race during background saves.

### Install or upgrade

For the downloaded app, allow Cue networking and choose **Check for Updates… → Install and Relaunch**, or quit Cue, open the DMG and replace your installed **Cue.app**. Use a writable Applications location. Settings and history are preserved. New installations and updates can require **System Settings → Privacy & Security → Accessibility** approval for window controls, clipboard paste and selected-text conversion. On macOS 27 this page is called **Device Control and Data Access**. If an old switch appears enabled but Cue reports no access, follow the [permission recovery guide](https://github.com/hsiuhsiu/cue/blob/v1.3.0/docs/chinese-conversion.md#permission-still-unavailable-after-rebuilding-or-updating).

For an existing source clone, quit Cue and run:

```sh
git pull --ff-only
./scripts/setup-local-signing.sh  # One-time setup on each Mac; safe to rerun.
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

**Command Line Tools with Swift 6 or later** suffice; full Xcode and a paid developer account are unnecessary. Future source updates only need `git pull --ff-only` and the install script. Keep the local Keychain identity; do not recreate it per update. Downloaded GitHub/Sparkle apps and Xcode builds use a different signing path and can require another permission grant. See the [source installation guide](https://github.com/hsiuhsiu/cue/blob/v1.3.0/docs/building.md).

Source builds default to Cue-owned networking and automatic checks **off**; official DMGs default to **on**. Saved user choices always take precedence.

### Validation and limitations

Optimized core and isolated native checks cover ranking, paste targeting/cancellation, consecutive layouts, Chinese composition, signing continuity and existing features on **Apple silicon / macOS 27.2 / Xcode 27**. Standalone Command Line Tools also build and validate the relocatable source bundle. Performance measurements use synthetic data and offscreen views, not physical input-to-display timing.

The user confirmed learned `HA` ranking, clipboard paste and consecutive custom layouts on this Mac. In a separate local update check, window actions worked after a second fixed-signature installation without changing Accessibility settings. This is not a guarantee after a system reset, identity change or future OS policy change. Chinese composition was checked with native simulated input; a physical input-method session and a positive real-Spotlight fixture were not repeated for this release. Intel and other macOS versions, a full public Sparkle download/install/relaunch cycle, live GPT/currency requests and power actions were not re-tested.

The public DMG remains **ad hoc signed, without Apple Developer ID signing or notarization**. Local fixed signing does not change that distribution limitation. Follow the [installation guide](https://github.com/hsiuhsiu/cue/blob/v1.3.0/docs/installation.md) for first-launch approval.

這次改善 App 搜尋學習、剪貼簿直接貼上、連續視窗配置與中文檔名輸入。自行建置的版本也能設定固定的本機簽署身分，讓後續更新沿用。

[下載 Cue 1.3.0](https://github.com/hsiuhsiu/cue/releases/download/v1.3.0/Cue-1.3.0-universal.dmg) · [校驗碼](https://github.com/hsiuhsiu/cue/releases/download/v1.3.0/SHA256SUMS.txt)

### 更新內容

- **依相同關鍵字學習排序：**輸入 `HA` 並選擇 Home Assistant 後，它能排在其他偶然部分符合的結果之前；既有學習資料會繼續使用。明確別名與完整名稱完全符合仍優先，一般使用頻率仍只影響同一符合類別。
- **剪貼簿歷史直接貼上：**按 **Return** 或 **Command+1–9** 會將選取的記錄貼回原 App；**拷貝／Command+Return** 保留只拷貝的操作。貼上需要輔助使用權限，缺少時會提供設定入口。Cue 會先核對原 App、視窗、輸入元件與剛拷貝的內容，並取消過期的交接。
- **連續視窗配置更可靠：**修正快速重複 **Option+M → 自訂數字** 時，視窗只移動一部分或面板未關閉的問題。Cue 保持原 App 在前景，核對實際調整結果；若舊位置限制了縮放，最多再修正一次。視窗調整仍預設啟用，已有的關閉選擇與面板關閉偏好都會保留。從選單列的**視窗設定…**可調整快捷鍵、配置及查看權限狀態。
- **中文組字即時更新搜尋：**例如 `f 身` 的檔名搜尋，會在輸入法組字期間跟隨畫面文字更新；Return 與方向鍵仍交給輸入法，直到確認選字。較晚完成的搜尋不會覆蓋新查詢或打斷組字；原生編輯元件也減少了長文字輸入的不必要排版工作。
- **自行建置可固定簽署：**執行一次 `./scripts/setup-local-signing.sh`，即可在這台 Mac 的鑰匙圈建立免費簽署身分；同一帳號後續建置或重新 clone 都自動沿用。首次切換仍需重新授權輔助使用一次，後續原始碼更新維持相同 App 身分。已設定的金鑰遺失、簽署身分不同或 App 損壞時，會停止建置或安裝，不會默默更換身分。不增加 App 執行時的工作，也沒有新增相依套件。
- **連結驗證：**在新版 macOS 上一致拒絕主機名稱含百分比編碼控制字元的網址。
- **匯率快取：**先完成檔案的私人存取權限，再一次替換更新後的匯率，排除背景儲存時的時序問題。

### 安裝或升級

下載版可在允許 Cue 自行連網後，選**檢查更新⋯ → 安裝並重新啟動**（**Install and Relaunch**）；或先結束 Cue，開啟 DMG 並取代已安裝的 **Cue.app**。請從可寫入的 Applications 位置執行，設定與歷史都會保留。新安裝與更新後，視窗調整、剪貼簿貼上及選取文字轉換可能需要到**系統設定 → 隱私權與安全性 → 輔助使用**授權；macOS 27 英文名稱為 **Device Control and Data Access**。若舊開關已開、Cue 卻仍顯示沒有權限，請依[授權排解說明](https://github.com/hsiuhsiu/cue/blob/v1.3.0/docs/chinese-conversion.md#重新建置或更新後仍顯示未取得權限)處理。

已有原始碼 clone 的話，先結束 Cue，再執行：

```sh
git pull --ff-only
./scripts/setup-local-signing.sh  # 每台 Mac 設定一次；重跑會沿用原身分。
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

只需 **Swift 6 以上的 Command Line Tools**，不必安裝完整 Xcode，也不需付費開發者帳號。之後更新只需要 `git pull --ff-only` 與安裝腳本。請保留鑰匙圈中的固定身分，不要每次更新都重新建立；GitHub／Sparkle 下載版與 Xcode 建置使用不同簽署流程，切換過去仍可能需要重新授權。詳見[原始碼安裝說明](https://github.com/hsiuhsiu/cue/blob/v1.3.0/docs/building.md)。

自行建置版預設關閉 Cue 自行連網與自動檢查更新，正式 DMG 預設開啟；使用者已儲存的選擇永遠優先。

### 驗證範圍與限制

在 **Apple silicon／macOS 27.2／Xcode 27** 執行最佳化核心與隔離原生檢查，涵蓋排序、貼上目標與取消、連續配置、中文組字、簽署身分連續性及既有功能。也使用獨立 Command Line Tools 建置並驗證可搬移的自行建置版。效能量測使用合成資料與離屏視窗，不代表實體按鍵到畫面的延遲。

使用者已在這台 Mac 確認 `HA` 學習排序、剪貼簿貼上與連續自訂配置正常；另外實測固定簽署版本更新後，不更動輔助使用設定就能直接調整視窗。這不代表系統重設、更換身分或未來系統政策改變後也一定保留授權。中文組字以原生模擬輸入檢查，本次未重跑實體輸入法操作及真實 Spotlight 正向案例；Intel、其他 macOS 版本、完整公開 Sparkle 下載／安裝／重啟流程、GPT／匯率真實請求與電源動作也未重新驗證。

公開 DMG 仍採用 **ad-hoc 簽章，沒有 Apple Developer ID 簽署與公證**；本機固定簽署不改變這個發布限制。首次開啟請依[安裝說明](https://github.com/hsiuhsiu/cue/blob/v1.3.0/docs/installation.md)核准。
