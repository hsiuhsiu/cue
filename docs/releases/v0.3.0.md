# Cue 0.3.0 — Clipboard and system commands / 剪貼簿與系統指令

## English

Cue 0.3.0 adds searchable clipboard history, Sleep and Lock Screen commands, and a smaller launcher with larger text and direct numbered shortcuts.

- **Clipboard History:** type `clipboard` or `剪貼簿` to open it. Recording starts **off**; enable it to save new copies of text and links. Existing clipboard contents are not imported when recording is enabled or resumed. Each record shows its copied date and time. Search, copy, or delete individual records; copying closes Cue, ready for **Command+V** in the destination app.
- **Settings where you need them:** use the clipboard page's gear or **Command+,** for recording and retention settings. Choose **1 hour**, **1 day**, **7 days** (default), **30 days**, or **No time limit**. Turning recording off stops new captures while saved records remain available and continue to expire.
- **Immediate numbered actions:** **Command+1–9** opens the matching app, runs the matching command, or copies the matching clipboard record without another Enter press. Clipboard **Copy** and **Delete** buttons show their shortcuts inline. **Delete/Backspace** removes the selected record when the query is empty; with query text, it edits the query. **Command+Backspace** deletes the selected record in either case.
- **A simpler launcher:** Cue initially shows only an empty input field. Larger input text and app names, balanced spacing, and blue tones inspired by the icon keep the interface compact. The window adapts to the result count and shows at most **nine matches without scrollbars**. Clipboard search still covers every saved record; refine the query to find older entries. **Command+,** from the main launcher opens Cue-wide Settings.
- **Sleep and Lock Screen:** type `sleep` / `睡眠` or `lock` / `鎖定`, then press Enter or the displayed Command+number. Cue closes immediately before requesting the action; neither command logs you out or closes your apps.

### Clipboard storage and limits

History stays on this Mac as readable text, with no separate encryption or cloud sync. It stores at most **500 items or 4 MiB of text**, removing the oldest when full even with no time limit. Copies larger than **256 KiB** are skipped. Images and files are not recorded. Known concealed, transient, and automatically generated clipboard markers are skipped, but source apps do not always supply them: Cue cannot identify every sensitive copy. Deleting a history entry does not clear the current system clipboard. See the [Clipboard History guide](https://github.com/hsiuhsiu/cue/blob/v0.3.0/docs/clipboard.md).

### Install or upgrade

[Download Cue 0.3.0](https://github.com/hsiuhsiu/cue/releases/download/v0.3.0/Cue-0.3.0-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v0.3.0/SHA256SUMS.txt)

- **Upgrade in Cue:** choose **Check for Updates…** from the menu bar or **Command+, → Updates** in the main launcher, then follow the download and **Install and Relaunch** prompts. Existing settings are preserved. Automatic checks can be disabled; you choose when to install and restart.
- **Install manually:** quit Cue if it is running, open the DMG, drag **Cue.app** into **Applications**, replace the old copy if needed, and open it there. Cue appears in the menu bar; **Option+Space** is the default shortcut. Use these steps if your copy has no update option.

Cue must run from a writable installed location to update itself, not directly from the read-only DMG. The app is ad hoc-signed and **not Apple-notarized**. Sparkle verifies signed update archives and feeds; this does not replace Developer ID signing or Apple's first-launch checks. If macOS blocks the first launch, use the app-specific approval steps in the [installation guide](https://github.com/hsiuhsiu/cue/blob/v0.3.0/docs/installation.md).

### Verification and known limits

Validated with optimized automated core, keyboard, clipboard, settings, localization, and system-command checks, plus manual UI checks. Clipboard checks use synthetic data and private pasteboards. Sleep/Lock routing and errors were tested with injected actions; **the Mac was not actually put to sleep or locked during validation**. Lock Screen uses a private macOS service and may need changes for future macOS versions. An updater installation from the public download on a second Mac remains unverified.

The universal app contains Apple silicon and Intel code and targets **macOS 14 or later**. Runtime testing was on **Apple silicon with macOS 26.6.2**; Intel and other macOS versions remain unverified.

## 正體中文

Cue 0.3.0 加入可搜尋的剪貼簿記錄、睡眠與鎖定螢幕指令，並以更精簡的啟動器、更大的文字及編號快速鍵加快操作。

- **剪貼簿記錄：**輸入 `clipboard` 或「剪貼簿」即可開啟。記錄功能**預設關閉**；啟用後才會保存新拷貝的文字與連結，啟用或恢復記錄時不會匯入剪貼簿原有內容。每筆記錄顯示拷貝日期時間，可搜尋、拷貝或逐筆刪除。拷貝後 Cue 會關閉，再到目的 App 按 **Command+V** 貼上。
- **在功能內調整設定：**剪貼簿頁的齒輪或 **Command+,** 可開啟記錄與保留時間設定。可選 **1 小時**、**1 天**、**7 天**（預設）、**30 天**或**不依時間清除**。關閉記錄只會停止擷取新內容，既有記錄仍可使用，也會繼續依保留期限清除。
- **編號快速執行：**按 **Command+1–9** 會直接開啟對應 App、執行指令或拷貝剪貼簿記錄，不必再按 Enter。剪貼簿的**拷貝**與**刪除**按鈕會直接顯示快速鍵。搜尋欄空白時，**Delete／Backspace** 會刪除所選記錄；有文字時則編輯搜尋文字。**Command+Backspace** 在兩種情況都可刪除所選記錄。
- **更精簡的啟動器：**剛叫出 Cue 時只有空白輸入欄。加大的輸入文字與 App 名稱、平衡的留白，以及呼應圖示的藍色色調，讓畫面清楚而緊湊。視窗依結果數量調整高度，最多顯示**九筆、不顯示捲軸**。剪貼簿搜尋仍涵蓋全部記錄，可輸入更精確的文字尋找較舊項目。在主啟動器按 **Command+,** 仍可開啟 Cue 的整體設定。
- **睡眠與鎖定螢幕：**輸入 `sleep`／「睡眠」或 `lock`／「鎖定」，再按 Enter 或畫面上的 Command+數字執行。Cue 會先立即關閉視窗，再要求系統執行；兩個指令都不會登出或關閉其他 App。

### 剪貼簿儲存與限制

記錄以可讀文字保存在這台 Mac，不另行加密，也不會同步到雲端。最多保留 **500 筆或 4 MiB 文字**；容量滿時會刪除最舊記錄，選擇不依時間清除也適用。超過 **256 KiB** 的單次拷貝會略過，不記錄圖片與檔案。帶有已知隱藏、暫存或自動產生剪貼簿標記的內容會被略過，但來源 App 不一定提供這些標記，因此 Cue 無法辨識所有敏感內容。刪除歷史記錄不會清空系統剪貼簿目前的內容。詳見[剪貼簿記錄說明](https://github.com/hsiuhsiu/cue/blob/v0.3.0/docs/clipboard.md)。

### 安裝或升級

[下載 Cue 0.3.0](https://github.com/hsiuhsiu/cue/releases/download/v0.3.0/Cue-0.3.0-universal.dmg) · [檢查碼](https://github.com/hsiuhsiu/cue/releases/download/v0.3.0/SHA256SUMS.txt)

- **從 Cue 更新：**在選單列選擇**檢查更新⋯**，或在主啟動器按 **Command+, → 更新**，依提示下載並**安裝與重新啟動**。既有設定會保留。自動檢查可以關閉，安裝與重啟的時機由你決定。
- **手動安裝：**若 Cue 正在執行，先結束 Cue；開啟 DMG，將 **Cue.app** 拖進**應用程式**，需要時取代舊版本，再從該位置開啟。Cue 會出現在選單列，預設快速鍵為 **Option+Space**。若目前版本沒有更新選項，也可使用此方式。

請從已安裝且可寫入的位置執行 Cue，才能自我更新；直接從唯讀 DMG 執行無法更新。App 使用 ad hoc 簽章，**尚未經 Apple 公證**。Sparkle 會驗證更新檔與更新資訊的簽章，但這不會取代 Developer ID 簽署或 Apple 的首次開啟檢查。若 macOS 阻擋首次開啟，請依[安裝說明](https://github.com/hsiuhsiu/cue/blob/v0.3.0/docs/installation.md)完成針對 Cue 的授權步驟。

### 驗證與已知限制

已通過最佳化建置的核心、鍵盤、剪貼簿、設定、翻譯與系統指令自動檢查，並進行實際介面檢查。剪貼簿檢查使用測試資料與獨立剪貼簿。睡眠與鎖定的執行路徑及錯誤處理使用替代動作驗證；**驗證過程未實際讓 Mac 睡眠或鎖定**。鎖定螢幕使用 macOS 私有服務，未來系統版本可能需要調整。尚未在另一台 Mac 驗證從公開下載來源進行更新安裝。

通用版包含 Apple silicon 與 Intel 程式碼，最低建置目標為 **macOS 14**。目前在 **Apple silicon、macOS 26.6.2** 實際執行測試；Intel 與其他 macOS 版本仍待驗證。
