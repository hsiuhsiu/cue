# Cue 1.1.0 — Command history and easier source installs / 指令歷史與更簡單的原始碼安裝

## English

Cue can now recall executed inputs with the arrow keys, and building your own copy no longer requires full Xcode.

[Download Cue 1.1.0](https://github.com/hsiuhsiu/cue/releases/download/v1.1.0/Cue-1.1.0-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v1.1.0/SHA256SUMS.txt)

### What's new

- **Recall previous commands:** open Cue with an empty input, press **↑** for older executed inputs and **↓** for newer ones. **Return** executes the recalled action; **Esc**, or moving past the newest entry, returns to blank. Editing ends recall and restores normal result-selection arrows. IME composition keeps control of its own keys.
- **Command History:** type **`history`**, **`command history`**, or **`指令歷史`** to search past inputs. Each page shows up to nine numbered entries with the action and date/time. **Use / Return** or **Command+1–9** restores an entry for review; press Return again in the launcher to execute. The original action is preserved, including Google versus GPT translation. A missing app, file or browser does not silently select a different action.
- **Local recording controls:** recording is **on by default**, including submitted Google/GPT text, calculations, conversions, filename queries and local commands. Failed execution attempts can also appear; drafts, responses, clipboard contents and text selected in other apps are excluded. Repeated input for the same action moves to the top. Limits are **200 entries, 30 days and 512 KiB of text**; inputs over 32 KiB are skipped. Delete a selected entry with **Command+Delete**, or plain **Delete** when the history search is empty. The page's gear / **Command+,** opens recording and clear-all controls. Turning recording off retains existing entries until deletion or expiry. History stays on this Mac, is excluded from settings backups, and is separate from search-ranking learning. See the [history guide](https://github.com/hsiuhsiu/cue/blob/v1.1.0/docs/command-history.md).
- **Source installation with Command Line Tools:** `scripts/install-app.sh` now builds an optimized, self-contained app with **Swift 6 or later Command Line Tools**. Full Xcode is optional for this installation path. Bundled languages, artwork, emoji, offline conversion dictionaries and Sparkle remain available after moving the app away from the checkout. See the [source installation guide](https://github.com/hsiuhsiu/cue/blob/v1.1.0/docs/building.md).

History loading and saving run in the background. Ordinary typing does not read or filter the history file; recall uses a bounded memory snapshot. Editing immediately after recall updates the input once, without restoring the old text over the first keystroke.

### Install or upgrade

If Cue networking is allowed, choose **Check for Updates…**, then **Install and Relaunch**. For a manual install, quit Cue, open the DMG, drag **Cue.app** into **Applications**, replace the existing copy if needed, and open it there. **Option+Space** opens Cue. Existing settings, clipboard history and search learning are preserved. Use a writable installation location, not the read-only DMG.

For a source install, run `xcode-select --install` if needed and wait for Command Line Tools installation to finish. Quit Cue, then run:

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

To update an existing clone, quit Cue, run `git pull --ff-only` and `./scripts/install-app.sh`, then reopen the installed app. Source builds default to Cue-owned networking and automatic checks **off**; official DMGs default to **on**. Explicit saved choices take precedence. Browser search has its own switch. An in-app update installs the published binary rather than compiling your clone.

### Validation and limitations

Validation uses optimized core tests, isolated feature checks, temporary preferences, private pasteboards, injected services and offscreen native views on **Apple silicon / macOS 27 / Xcode 27**. Command History is checked in both English and Traditional Chinese. The source installation path was built and its relocated resources/signatures verified using standalone **Command Line Tools / Swift 6.4**. Offscreen timing measurements do not establish physical input-to-display latency.

The universal download targets **macOS 14 or later**, with both Apple silicon and Intel code. Intel and other macOS versions were not tested on hardware. This release does not include a fresh installed-app desktop check or an end-to-end public Sparkle download/install/relaunch test. Live GPT/currency requests, Spotlight indexing, power actions and macOS permission flows were not re-tested; their isolated checks do not prove live behavior.

Cue remains **ad hoc signed, without Apple Developer ID signing or notarization**. Sparkle's update signatures do not replace Apple's first-launch approval. Follow the [installation guide](https://github.com/hsiuhsiu/cue/blob/v1.1.0/docs/installation.md) if macOS blocks opening. Window controls and selected-text conversion may need permission granted again for the updated executable.

## 正體中文

Cue 現在可以用方向鍵回看已執行的輸入，自行編譯安裝也不再需要完整 Xcode。

[下載 Cue 1.1.0](https://github.com/hsiuhsiu/cue/releases/download/v1.1.0/Cue-1.1.0-universal.dmg) · [校驗碼](https://github.com/hsiuhsiu/cue/releases/download/v1.1.0/SHA256SUMS.txt)

### 新功能

- **回看先前指令：**叫出 Cue，在空白輸入欄按 **↑** 看較舊的已執行輸入，按 **↓** 看較新的記錄。**Return** 執行回看的動作；**Esc** 或往下超過最新一筆會回到空白。修改文字就結束回看，恢復原本上下鍵選取結果的操作；中文組字仍保有自己的按鍵操作。
- **指令歷史：**輸入 **`history`**、**`command history`** 或**「指令歷史」**搜尋過去的輸入。每頁最多九筆，顯示編號、動作與日期時間。按**使用／Return** 或 **Command+1–9** 將輸入放回主視窗，確認後再按 Return 執行。會保留原本的動作，例如 Google 搜尋或 GPT 翻譯；App、檔案或瀏覽器找不到時，不會偷偷改選另一個動作。
- **本機記錄控制：**記錄**預設開啟**，包含送出的 Google／GPT 文字、計算式、換算、檔名查詢及本機指令，也可能包含執行失敗的嘗試。草稿、回答、剪貼簿內容及其他 App 選取的文字不記錄。相同輸入執行相同動作會移到最上方。最多 **200 筆、30 天、512 KiB 文字**；超過 32 KiB 的輸入不記錄。按 **Command+Delete** 刪除選取記錄，搜尋欄空白時也能直接按 **Delete**。該頁齒輪／**Command+,** 可關閉記錄或清空全部；關閉記錄後，既有內容保留到刪除或到期。歷史只存這台 Mac、不隨設定備份，也不加入搜尋排序學習。詳見[指令歷史說明](https://github.com/hsiuhsiu/cue/blob/v1.1.0/docs/command-history.md)。
- **只用 Command Line Tools 即可安裝：**`scripts/install-app.sh` 現在以 **Swift 6 以上的 Command Line Tools** 編譯並打包最佳化 App，這條安裝路徑不需完整 Xcode。雙語資源、圖示、emoji、離線繁簡詞庫與 Sparkle 都包含在 App 裡，移離儲存庫後仍可使用。詳見[原始碼安裝指引](https://github.com/hsiuhsiu/cue/blob/v1.1.0/docs/building.md)。

歷史的載入與存檔在背景進行；一般打字不讀取或搜尋歷史檔案，上下鍵只使用有容量限制的記憶體快照。回看後立即修改文字，只更新一次輸入，不會把舊文字蓋回第一個按鍵。

### 安裝或升級

允許 Cue 自行連網後，可選**檢查更新⋯**，再依提示**安裝並重新啟動**（**Install and Relaunch**）。手動安裝則先結束 Cue，開啟 DMG，將 **Cue.app** 拖入 **Applications／應用程式**，需要時取代舊版，再從該位置開啟。按 **Option+Space** 叫出 Cue。既有設定、剪貼簿記錄與搜尋學習資料會保留；請從可寫入的安裝位置執行，不要直接在唯讀 DMG 內更新。

自行編譯時，若尚未安裝 Command Line Tools，先執行 `xcode-select --install` 並等安裝完成。結束 Cue 後執行：

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

更新既有 clone 時，先結束 Cue，在儲存庫執行 `git pull --ff-only` 與 `./scripts/install-app.sh`，再開啟已安裝的 App。原始碼版預設**關閉** Cue 自行連網與自動檢查更新，正式 DMG 預設**開啟**；已儲存的明確選擇優先，瀏覽器搜尋另有獨立開關。Cue 內的更新會安裝發布的執行檔，不會替 clone 編譯。

### 驗證與限制

驗證在 **Apple silicon／macOS 27／Xcode 27** 執行最佳化核心測試與隔離功能檢查，使用暫存設定、專用測試剪貼簿、注入服務及離屏原生介面。指令歷史涵蓋英文與正體中文；原始碼安裝路徑也已使用獨立的 **Command Line Tools／Swift 6.4** 完成建置，並驗證移動後的資源與簽章。離屏元件量測不等同實際按鍵到螢幕的延遲。

通用版最低目標為 **macOS 14**，包含 Apple silicon 與 Intel 執行檔；Intel 與其他 macOS 版本未做實機驗證。本輪沒有重新驗證最終安裝版本的桌面操作，也未完成公開 Sparkle 下載／安裝／重啟全流程；真實 GPT／匯率請求、Spotlight 索引、電源操作及 macOS 權限流程也未重測，隔離檢查不能代替這些實際操作。

Cue 維持 **ad hoc 簽章，沒有 Apple Developer ID 簽署，也未經 Apple 公證**。Sparkle 更新簽章不取代 Apple 的首次開啟允許程序；若 macOS 阻擋，請依[安裝說明](https://github.com/hsiuhsiu/cue/blob/v1.1.0/docs/installation.md)處理。更新執行檔後，視窗控制及選取文字轉換可能需要重新授權。
