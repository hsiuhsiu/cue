# Cue 1.1.1 — App discovery and multiline input / App 搜尋與多行輸入修正

## English

This patch improves application discovery and makes long launcher inputs easier to read.

[Download Cue 1.1.1](https://github.com/hsiuhsiu/cue/releases/download/v1.1.1/Cue-1.1.1-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v1.1.1/SHA256SUMS.txt)

### Fixes

- **More app folders are searchable:** localized containers such as `~/Applications/Chrome Apps.localized` are searched even when Finder marks them as packages. Visible symbolic links to application folders are followed, with protection against loops and duplicates. Hidden folders and app-bundle contents remain excluded. Cue uses the current user's home directory; no username is hardcoded. Run **Update App Index** after installing or moving apps.
- **Long input expands to two lines:** the launcher keeps its current width and text size, growing only in height when needed. Longer content remains intact and scrolls with the caret within the two-line limit. Return still executes the selected action; result navigation, command-history recall and Chinese input composition keep their existing behavior.
- **Typing stays lightweight:** input sizing reuses cached measurements and examines only a bounded amount of text. Editing avoids an unnecessary full-text read, and application discovery stays in the background.

### Install or upgrade

With Cue networking allowed, choose **Check for Updates…**, then **Install and Relaunch**. For a manual install, quit Cue, open the DMG, drag **Cue.app** into **Applications**, replace the existing copy, and reopen it. Existing settings and history are preserved. Use a writable installation location rather than running from the DMG.

Source installs still need only **Command Line Tools with Swift 6 or later**, not full Xcode. For an existing clone, quit Cue, run `git pull --ff-only` and `./scripts/install-app.sh`, then reopen the installed app. New users can follow the [source installation guide](https://github.com/hsiuhsiu/cue/blob/v1.1.1/docs/building.md). Source builds default to Cue-owned networking and automatic checks **off**; official DMGs default to **on**. Explicit saved choices take precedence. Browser search has its own switch.

### Validation and limitations

Optimized core tests and isolated feature checks run on **Apple silicon / macOS 27 / Xcode 27**, using synthetic data, temporary preferences, private pasteboards and offscreen native views. App discovery covers localized folders, Finder package flags, symbolic links and cycles. Native input checks cover English and Chinese wrapping, long pasted text, caret scrolling, history recall and input-method composition. The source installation path was also built and its relocated resources/signatures verified using standalone **Command Line Tools / Swift 6.4**. Timing measurements are offscreen checks, not physical input-to-display latency measurements.

The universal download targets **macOS 14 or later** and contains Apple silicon and Intel code. Intel and other macOS versions were not tested on hardware. This release does not include a fresh installed-app desktop check or a full public Sparkle download/install/relaunch test. Live GPT/currency requests, Spotlight indexing, power actions and macOS permission flows were not re-tested.

Cue remains **ad hoc signed, without Apple Developer ID signing or notarization**. Sparkle signatures do not replace Apple's first-launch approval. Follow the [installation guide](https://github.com/hsiuhsiu/cue/blob/v1.1.1/docs/installation.md) if macOS blocks opening. Window controls and selected-text conversion may need permission granted again for the updated executable.

## 正體中文

這次修正擴充 App 資料夾的搜尋支援，也讓主視窗的長輸入更容易閱讀。

[下載 Cue 1.1.1](https://github.com/hsiuhsiu/cue/releases/download/v1.1.1/Cue-1.1.1-universal.dmg) · [校驗碼](https://github.com/hsiuhsiu/cue/releases/download/v1.1.1/SHA256SUMS.txt)

### 修正內容

- **支援更多 App 資料夾：**`~/Applications/Chrome Apps.localized` 這類本地化資料夾，即使被 Finder 標記為套件，也會搜尋其中的 App。同時支援指向 App 資料夾的可見符號連結，避免連結循環及重複項目；隱藏資料夾與 App 套件內部仍會略過。家目錄依目前使用者決定，不會寫死使用者名稱。安裝或移動 App 後，可執行**更新索引**。
- **長輸入自動展開至兩行：**保留原本的視窗寬度與字體大小，只在需要時增加高度。超過兩行的完整內容仍保留，並在兩行範圍內隨游標捲動。Return 仍執行選取動作；結果選取、指令歷史回看與中文組字維持原本操作。
- **維持輕量的輸入流程：**重用文字高度量測，並限制每次檢查的文字量；編輯時避免多餘的全文讀取，App 掃描也持續在背景執行。

### 安裝或升級

允許 Cue 自行連網後，選**檢查更新⋯**，再依提示**安裝並重新啟動**（**Install and Relaunch**）。手動安裝則先結束 Cue，開啟 DMG，將 **Cue.app** 拖入 **Applications／應用程式**，取代舊版後重新開啟。既有設定與記錄會保留；請從可寫入的安裝位置執行，不要直接在唯讀 DMG 內更新。

自行編譯仍只需要 **Swift 6 以上的 Command Line Tools**，不需完整 Xcode。更新既有 clone 時，先結束 Cue，執行 `git pull --ff-only` 與 `./scripts/install-app.sh`，再開啟已安裝的 App。首次安裝可參考[原始碼安裝指引](https://github.com/hsiuhsiu/cue/blob/v1.1.1/docs/building.md)。原始碼版預設**關閉** Cue 自行連網與自動檢查更新，正式 DMG 預設**開啟**；已儲存的明確選擇優先，瀏覽器搜尋另有獨立開關。

### 驗證與限制

最佳化核心測試與隔離功能檢查在 **Apple silicon／macOS 27／Xcode 27** 執行，使用合成資料、暫存設定、專用測試剪貼簿及離屏原生介面。App 搜尋涵蓋本地化資料夾、Finder 套件標記、符號連結及循環；原生輸入檢查涵蓋英文與中文換行、長文字貼上、游標捲動、歷史回看及輸入法組字。原始碼安裝路徑也已使用獨立的 **Command Line Tools／Swift 6.4** 完成建置，並驗證移動後的資源與簽章。離屏效能量測不等同實際按鍵到螢幕的延遲。

通用版最低目標為 **macOS 14**，包含 Apple silicon 與 Intel 執行檔；Intel 與其他 macOS 版本未做實機驗證。本輪沒有重新驗證最終安裝版本的桌面操作，也未完成公開 Sparkle 下載／安裝／重啟全流程；真實 GPT／匯率請求、Spotlight 索引、電源操作及 macOS 權限流程也未重測。

Cue 維持 **ad hoc 簽章，沒有 Apple Developer ID 簽署，也未經 Apple 公證**。Sparkle 更新簽章不取代 Apple 的首次開啟允許程序；若 macOS 阻擋，請依[安裝說明](https://github.com/hsiuhsiu/cue/blob/v1.1.1/docs/installation.md)處理。更新執行檔後，視窗控制及選取文字轉換可能需要重新授權。
