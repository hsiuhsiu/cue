# Cue 0.6.0 — Emoji and web tools / Emoji 與網頁工具

## English

Cue 0.6.0 adds offline emoji search, Google search with your choice of browser,
and local clipboard link cleaning.

- **Emoji search:** type **`emoji`** or **`表情符號`** to open a dedicated page.
  Search English or Traditional Chinese keywords, select with the arrow keys
  and Return, double-click, choose **Copy**, or press **Command+1–9** to copy an emoji and close Cue.
  Paste with Command+V in the destination app; Cue does not paste automatically.
  Esc returns to the launcher. The catalog is bundled, works offline from first
  use, and shows at most nine matches without a scrollbar.
- **Google search:** when a nonempty main-launcher query has no local app or
  command match after the first index loads, Cue offers Google search.
  **Command+Return** searches the current text in your default browser even
  when local results exist. **Command+K** shows browser actions for that text;
  ordinary Return still runs the selected local result. Typing and input-method
  composition do not send searches or fetch suggestions.
- **Your browsers:** search **`google settings`** to add or remove up to eight
  browser choices alongside the system default. Only browsers you choose enter
  the list, each Mac keeps its own choices, and the result artwork shows the
  browser's icon. A missing browser reports an error instead of silently using
  another. Command-comma on a Google action opens these feature settings.
- **Link cleaner:** copy one HTTP(S) link, then run **`clean link`**,
  **`link cleaner`**, **`清理連結`**, or **`清理網址`**. Cue removes known tracking
  parameters, preserving other parameters, fragments, and their encoding.
  Recognized signed links stay unchanged; ambiguous semicolon fields are
  retained. The result reports the removed count or why the clipboard remains
  unchanged. Cleaning runs locally, does not expand short links or redirects,
  open a browser, or paste automatically. A detected newer copy prevents a
  pending cleanup from replacing it.
- **Clear network and privacy controls:** Cue's global network switch continues
  to govern its own requests, including updates. Explicit Google searches use
  an independent **Enable Google search** switch, on by default, so they can
  still hand off to your browser when Cue's own networking is off. Turn that
  feature switch off to block the handoff too. The browser and Google receive
  only submitted queries and apply their own settings. Emoji search and link
  cleaning stay offline. Google queries, Emoji page searches/selections, and
  cleaned clipboard URLs are not saved in Cue's search-learning history.

See the [Emoji](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/emoji.md),
[Google search](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/web-search.md), and
[link cleaner](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/link-cleaner.md) guides.

### Install or upgrade

[Download Cue 0.6.0](https://github.com/hsiuhsiu/cue/releases/download/v0.6.0/Cue-0.6.0-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v0.6.0/SHA256SUMS.txt)

With Cue's network access enabled, choose **Check for Updates… → Install and
Relaunch**. Or quit Cue, open the DMG, and drag **Cue.app** into **Applications**,
replacing the old copy. Open the installed app; its default shortcut is
**Option+Space**. Settings, clipboard history, and search learning are preserved.
Updating requires a writable installed location, not the read-only DMG.
Automatic downloads and unattended installation remain disabled.

To compile your own copy, install full **Xcode with Swift 6 or later**, open it
once to finish its license and setup, quit Cue, then run:

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

The optimized app stays installed at `~/Applications/Cue.app`. The first build
downloads the pinned Sparkle dependency; Chinese dictionaries and the emoji
catalog are already bundled. To update a source build, quit Cue and run
`git pull --ff-only` followed by `./scripts/install-app.sh`. Source builds default
to Cue's own networking and automatic update checks **off**; official DMGs
default to **on**. Explicit saved choices are preserved. Browser search has its
own enabled-by-default switch in both builds. Installing an update offered by
Cue replaces a source build with the published app. See the
[source guide](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/building.md) and
[network policy](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/network-policy.md).

The app is ad hoc-signed, **without Developer ID signing or Apple notarization**.
If macOS blocks its first launch, follow the app-specific
[installation instructions](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/installation.md).
Chinese text replacement still needs Accessibility permission for the installed
copy; rebuilding or updating can invalidate an older grant.

The universal app targets **macOS 14+**, with Apple silicon and Intel binaries.
Runtime verification is on **Apple silicon / macOS 27.0 / Xcode 27**; Intel,
other macOS versions, and a public update installation on a second Mac remain
unverified. System-action checks use substitutes; actual sleep, lock, display-off,
and logout/reboot startup cycles have not been verified for this release.

## 正體中文

Cue 0.6.0 加入離線 Emoji 搜尋、可選擇瀏覽器的 Google 搜尋，以及本機剪貼簿
連結清理。

- **Emoji 搜尋：**輸入 **`emoji`** 或 **`表情符號`** 開啟專用頁面。用英文或
  正體中文關鍵字搜尋，以方向鍵選取後按 Return、按兩下結果、按**拷貝**，或按 **Command+1–9**，
  即可拷貝 emoji 並收起 Cue。到目標 App 按 Command+V 貼上，Cue 不會自動
  貼入；Esc 返回主搜尋。目錄隨 App 內附，首次使用也離線，最多顯示九個
  符合結果、不顯示捲軸。
- **Google 搜尋：**初次索引完成後，主搜尋的非空白文字若沒有符合的 App 或
  指令，就會提供 Google 搜尋。即使已有本機結果，也可用 **Command+Return**
  在預設瀏覽器搜尋目前文字；**Command+K** 顯示這段文字的瀏覽器動作。
  一般 Return 仍執行選取的本機結果。打字或輸入法組字時不會傳送搜尋或取得
  搜尋建議。
- **選擇自己的瀏覽器：**輸入 **`Google 搜尋設定`**，可在系統預設之外自行
  加入、移除最多八個瀏覽器。只有明確選擇的 App 會進入清單，每台 Mac 各自
  保留選擇，結果圖示也會標示對應瀏覽器。若已加入的瀏覽器不存在，會顯示
  錯誤，不會悄悄換用其他瀏覽器；選到 Google 動作時，Command+逗號可開啟
  這個功能的設定。
- **連結清理：**複製一個 HTTP(S) 網址，執行 **`clean link`**、**`link cleaner`**、
  **`清理連結`**或 **`清理網址`**，即可移除已知追蹤參數，保留其他參數、
  網址片段及原有編碼。已識別的簽章網址不修改，解析方式不明確的分號欄位
  也會保留。結果顯示移除數量或剪貼簿保持原樣的原因。清理在本機進行，
  不展開短網址或重新導向、不開啟瀏覽器、不自動貼上；若等待期間偵測到
  較新的拷貝，就不覆蓋它。
- **明確的網路與隱私控制：**全域網路開關持續管理 Cue 自己的請求，包括更新。
  明確執行的 Google 搜尋使用獨立、預設開啟的**啟用 Google 搜尋**開關；因此
  Cue 自行連網關閉時，仍可主動交給瀏覽器搜尋。若也要阻止此交接，請關閉
  該功能開關。瀏覽器及 Google 只接收已送出的查詢，依各自設定處理。
  Emoji 搜尋與連結清理維持離線。Google 字詞、Emoji 頁面搜尋／選取結果，
  以及清理的剪貼簿網址，都不會存入 Cue 的搜尋學習記錄。

詳見 [Emoji](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/emoji.md)、
[Google 搜尋](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/web-search.md)與
[連結清理](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/link-cleaner.md)說明。

### 安裝或升級

[下載 Cue 0.6.0](https://github.com/hsiuhsiu/cue/releases/download/v0.6.0/Cue-0.6.0-universal.dmg) · [檢查碼](https://github.com/hsiuhsiu/cue/releases/download/v0.6.0/SHA256SUMS.txt)

允許 Cue 使用網路後，選擇**檢查更新⋯ → 安裝與重新啟動**；或先結束 Cue，
開啟 DMG，將 **Cue.app** 拖進**應用程式**取代舊版，再開啟安裝好的 App。
預設快速鍵為 **Option+Space**，設定、剪貼簿記錄與搜尋學習資料都會保留。
更新需要可寫入的安裝位置，不能直接在唯讀 DMG 中執行。自動下載及無人操作
安裝仍維持停用。

自行編譯需要內含 **Swift 6 以上的完整 Xcode**，先開啟完成授權與設定、結束 Cue，
再執行：

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

最佳化 App 會固定安裝至 `~/Applications/Cue.app`。首次建置下載固定版本的
Sparkle；中文詞庫與 emoji 目錄已經內附。來源版更新時，先結束 Cue，執行
`git pull --ff-only` 與 `./scripts/install-app.sh`。自行建置版預設**關閉** Cue
自行連網與自動檢查更新，正式 DMG 預設**開啟**；明確儲存的選擇會保留。
兩種版本的瀏覽器搜尋皆有獨立、預設開啟的開關。若從 Cue 安裝提供的更新，
會將來源版換成發布版。詳見[原始碼指引](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/building.md)
及[網路政策](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/network-policy.md)。

App 使用 ad hoc 簽章，**沒有 Developer ID 簽署，也未經 Apple 公證**。若 macOS
阻擋首次開啟，請依針對 Cue 的[安裝說明](https://github.com/hsiuhsiu/cue/blob/v0.6.0/docs/installation.md)
操作。簡繁文字取代仍需要為目前安裝的 Cue 開啟輔助使用權限；重新建置或更新
可能使舊授權失效。

通用版目標為 **macOS 14+**，包含 Apple silicon 與 Intel 執行檔。實際執行驗證
環境為 **Apple silicon／macOS 27.0／Xcode 27**；Intel、其他 macOS 版本，以及
另一台 Mac 從公開來源更新安裝，仍未驗證。系統指令檢查使用替代動作；本次
發布尚未實際驗證睡眠、鎖定、關閉顯示器及登出／重開機後啟動的完整循環。
