# Cue 1.0.0 — Your everyday keyboard toolkit / 日常鍵盤工具箱

## English

Cue 1.0 brings window controls, portable settings and filename search to its
native macOS launcher, alongside the existing clipboard, text, calculation and
GPT tools. Fast, simple and lightweight remain its core principles.

[Website](https://yihsiu.org/cue/) · [Download Cue 1.0.0](https://github.com/hsiuhsiu/cue/releases/download/v1.0.0/Cue-1.0.0-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v1.0.0/SHA256SUMS.txt)

### What's new

- **Window controls:** press **Option+M** for the current window. Use
  **Option+arrows** for halves, **Command+arrows** to move between displays,
  **Return** to fill the usable desktop without creating a fullscreen Space,
  **Space** to center, **Tab** to restore, and **1–9** for saved percentage
  layouts. Choose whether the panel stays open after an adjustment.
  The feature defaults to **on**, including upgrades without a saved window
  configuration; an explicitly saved off choice is preserved. Open
  **Window Settings…** from Cue's menu bar, search `window settings`, or press
  **Command+,** in window mode to configure it.
- **Permission guidance for new and existing users:** window controls require
  macOS **Privacy & Security → Accessibility** permission, called **Device
  Control and Data Access** in macOS 27. Missing or revoked permission opens a
  guide with the actual status, a system-settings link and **Check Again**.
  Returning from System Settings refreshes the status; no prompt appears just
  because Cue starts, and old layout actions are not replayed. A grant from an
  older executable may no longer be valid after an update. If the system switch
  is on but Cue remains untrusted, follow the
  [current-app recovery steps](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/window-controls.md#新安裝與更新後的授權).
- **Settings backup and transfer:** **Settings → Backup & Transfer** exports
  portable preferences, aliases, selected browsers and window layouts. Imports
  show a selectable preview and preserve the destination Mac's network, recording,
  window-enablement, startup and permission choices. Ordinary JSON excludes API
  keys. Optional password protection encrypts the backup; including an OpenAI key
  requires encryption and an additional explicit choice. Passwords require at
  least 12 characters and are not saved or recoverable. Clipboard contents and
  search-learning history are excluded. See the
  [backup guide](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/settings-portability.md).
- **Filename search:** type **`f` + space + a filename fragment**, for example
  `f report` or `f 發票`. Search local Spotlight metadata for files and folders;
  use **Return** or **Command+1–9** to open a result in its default app. Results
  show parent paths and stay within nine rows. Cue does not scan document contents,
  search network volumes or send file queries to Google/GPT. It works with Cue
  networking off and depends on Spotlight's indexing, exclusions and access rules.
  Known APFS data-volume aliases are normalized so eligible user files are not
  mistaken for system files. See the
  [file-search guide](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/file-search.md).
- **Responsiveness and reliability:** app matching reuses prepared name data;
  icon decoding and caches have bounded concurrency and size. File refinements
  retain still-matching rows and panel height while pending, then preserve
  numbered choices once navigation begins. Background cancellation rejects stale
  results, input edits publish one coherent update, and unchanged clipboard
  expiration checks avoid unnecessary sorting. These changes add no typing debounce.
- **Clear versions and MIT licensing:** Settings, About and update dialogs show
  **1.0.0** without a parenthesized internal build number. Update ordering keeps
  its separate increasing counter. Cue is now distributed under the
  [MIT License](https://github.com/hsiuhsiu/cue/blob/v1.0.0/LICENSE); bundled
  third-party components and data retain their own licenses.

### Install or upgrade

With Cue networking allowed, choose **Check for Updates…**, then download and
**Install and Relaunch**. To install manually, quit Cue, open the DMG, drag
**Cue.app** into **Applications**, replace an existing copy if needed, then open
it there. The app lives in the menu bar; **Option+Space** opens the launcher.
Settings, clipboard history and search learning are preserved. Updating needs a
writable installed location, not the read-only DMG; installation and restart
remain your choice.

To build your own copy, install full Xcode with Swift 6 or later, complete its
license/setup, quit any running Cue, then run:

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

For source updates, quit Cue and run `git pull --ff-only` and
`./scripts/install-app.sh`, then reopen it. Source builds default to Cue-owned
networking and automatic checks **off**; official DMGs default to **on**. Saved
choices take precedence. Explicit browser search has its own switch. Installing
an in-app update replaces a source build with the published binary; it does not
compile your repository. See the
[source guide](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/building.md).

### Verification and limits

The pre-release review passed **287 optimized core tests**, 30 groups of isolated
feature/integration checks, and Apple silicon/Intel compilation. Tests use
synthetic data, private pasteboards, temporary preferences, injected services and
offscreen native views. Host checks ran on **Apple silicon / macOS 27.0 / Xcode
27**. Component performance measurements do not establish keyboard-to-display
latency or a comparison with other launchers.

This round did **not** complete a live-desktop check of the final installed app,
multi-display/app compatibility, fresh or updated macOS permission flows, or a
full public Sparkle download/install/relaunch. A positive real-Spotlight fixture
remained inconclusive: both Cue and macOS `mdfind` returned no match for the
new fixture, despite metadata being visible. Injected positive-result checks
passed; they do not prove a target Mac's index is searchable. Real GPT/currency
requests and sleep/lock/display-off/login cycles were not rerun.

The universal app targets **macOS 14+**, but **Intel and macOS versions other than
27 were not runtime-tested**. App size constraints can limit window adjustments;
macOS Secure Input may intercept Option+letter shortcuts, so use Window Settings
to choose another combination when needed.

Cue is **ad hoc-signed, without Apple Developer ID signing or notarization**.
Sparkle's update signatures do not replace Apple's first-launch checks. If macOS
blocks opening the app, use the app-specific approval steps in the
[installation guide](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/installation.md).
Window controls and Chinese text replacement need permission for the currently
installed copy; rebuilding or updating can invalidate an older grant.

## 正體中文

Cue 1.0 將視窗調整、設定移轉與檔名搜尋加入原生 macOS 啟動器，搭配既有的
剪貼簿、文字處理、計算及 GPT 工具。快速、簡潔、輕量仍是核心原則。

[官網](https://yihsiu.org/cue/) · [下載 Cue 1.0.0](https://github.com/hsiuhsiu/cue/releases/download/v1.0.0/Cue-1.0.0-universal.dmg) · [檢查碼](https://github.com/hsiuhsiu/cue/releases/download/v1.0.0/SHA256SUMS.txt)

### 新功能與改善

- **視窗調整：**按 **Option+M** 控制目前視窗。**Option+方向鍵**套用半屏、
  **Command+方向鍵**移動顯示器、**Return** 填滿可用桌面而不建立全螢幕 Space、
  **空白鍵**置中、**Tab** 還原、**1–9** 套用已儲存的比例配置；可設定調整後
  是否保留面板。功能**預設啟用**，包含尚無視窗設定的舊版升級；明確儲存的
  關閉選擇會保留。從 Cue 選單列選擇**視窗設定…**、搜尋 `window settings`，
  或在視窗模式按 **Command+,** 即可調整。
- **新安裝與更新後的授權引導：**視窗調整需要 macOS **隱私權與安全性 →
  輔助使用**權限；macOS 27 英文名稱為 **Device Control and Data Access**。
  缺少或撤銷權限時，會顯示實際狀態、系統設定入口與**重新檢查**。從系統設定
  返回會更新狀態；Cue 啟動時不直接索取權限，也不重播授權前的配置操作。
  更新後，舊執行檔的授權不一定仍有效。若系統開關已開啟但 Cue 仍未獲信任，
  請依[目前安裝版本的排解步驟](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/window-controls.md#新安裝與更新後的授權)處理。
- **設定備份與移轉：**在**設定 → 備份與移轉**匯出偏好、別名、指定瀏覽器與
  視窗配置；匯入前可預覽並選擇區塊，保留目的 Mac 的網路、記錄、視窗啟用、
  登入啟動與權限選擇。一般 JSON 不含 API key；可選密碼加密，攜帶 OpenAI
  金鑰則必須加密並另外明確勾選。密碼至少 12 個字元，不會儲存，忘記後無法
  復原。剪貼簿內容與搜尋學習記錄不列入備份。詳見
  [備份說明](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/settings-portability.md)。
- **檔名搜尋：**輸入 **`f`＋空格＋部分檔名**，例如 `f report` 或 `f 發票`，
  即可透過本機 Spotlight 索引搜尋檔案及資料夾。按 **Return** 或
  **Command+1–9** 用預設 App 開啟；結果顯示所在路徑，最多九列。Cue 不讀取
  文件內容、不搜尋網路磁碟，也不把檔案查詢交給 Google／GPT。關閉 Cue 網路
  仍可使用，結果依 Spotlight 索引、排除範圍及權限而定。已正規化已知的 APFS
  資料卷宗別名，避免一般使用者檔案被當成系統檔案排除。詳見
  [檔案搜尋說明](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/file-search.md)。
- **操作反應與穩定性：**App 比對重用預先整理的名稱；圖示解碼及快取都有
  工作數量與容量上限。檔案查詢尚未完成時保留仍符合的列及視窗高度，開始
  選取後固定編號。取消機制拒絕過期回覆、每次輸入編輯只發布一次完整更新，
  剪貼簿沒有過期項目時也避免重複排序。這些改善不加入打字等待或 debounce。
- **清楚的版號與 MIT 授權：**設定、「關於」及更新視窗顯示 **1.0.0**，不再
  附上括號建置號；更新排序仍使用獨立遞增的內部編號。Cue 採用
  [MIT 授權](https://github.com/hsiuhsiu/cue/blob/v1.0.0/LICENSE)，內附的第三方
  元件及資料維持各自授權。

### 安裝或升級

允許 Cue 自行連網後，選擇**檢查更新⋯**、下載，再依提示**安裝並重新啟動**
（**Install and Relaunch**）。也可先結束 Cue，開啟 DMG，將 **Cue.app** 拖入
**Applications／應用程式**，需要時取代舊版，再從該位置開啟。Cue 常駐選單列，
按 **Option+Space** 叫出主視窗。設定、剪貼簿記錄與搜尋學習資料會保留。
更新需要可寫入的安裝位置，不能直接在唯讀 DMG 裡執行；安裝與重啟由你選擇。

自行建置需先安裝含 Swift 6 以上的完整 Xcode、完成授權與設定，並結束正在
執行的 Cue，再執行：

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

日後更新原始碼版時，先結束 Cue，執行 `git pull --ff-only` 與
`./scripts/install-app.sh`，再開啟。原始碼版預設**關閉** Cue 自行連網與自動
檢查更新，正式 DMG 預設**開啟**；已儲存的明確選擇優先。瀏覽器搜尋另有獨立
開關。從 Cue 內安裝更新會換成發布的執行檔，不會替儲存庫編譯。詳見
[原始碼指引](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/building.md)。

### 驗證與限制

發布前審查通過 **287 項最佳化核心測試**、30 組隔離功能／整合檢查，以及
Apple silicon／Intel 編譯。測試採用合成資料、專用測試剪貼簿、暫存設定、
注入服務及離屏原生介面；執行環境為 **Apple silicon／macOS 27.0／Xcode 27**。
元件效能量測不等同按鍵到畫面的總延遲，也不是與其他啟動器的比較。

本輪**尚未完成**最終安裝版本的實際桌面驗證、多顯示器／不同 App 相容性、
全新或更新後的 macOS 授權流程，以及完整的公開 Sparkle 下載／安裝／重啟。
真實 Spotlight 正向測試仍無法下結論：新建測試檔雖可讀到 metadata，Cue 與
macOS `mdfind` 都找不到。模擬正向結果檢查已通過，但不能證明目標 Mac 的
索引能搜尋到檔案。本輪也未重跑真實 GPT／匯率請求，以及睡眠、鎖定、關閉
顯示器或登入啟動循環。

通用版最低目標為 **macOS 14**，但 **Intel 與 macOS 27 以外的版本未做實機
執行驗證**。App 的尺寸限制可能影響視窗調整；macOS 安全輸入也可能攔截
Option＋字母，遇到時可在視窗設定改用其他組合。

Cue 使用 **ad hoc 簽章，沒有 Apple Developer ID 簽署，也未經 Apple 公證**。
Sparkle 更新簽章不會取代 Apple 的首次開啟檢查。若 macOS 阻擋啟動，請依
[安裝說明](https://github.com/hsiuhsiu/cue/blob/v1.0.0/docs/installation.md)完成針對
Cue 的允許程序。視窗調整及簡繁文字取代需要授權目前安裝的那份 App；重新
建置或更新可能使舊授權失效。
