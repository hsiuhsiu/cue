## English

Cue is a native macOS launcher that lives in the menu bar and lets you search and open installed apps with the keyboard. Downloads are publicly available.

Open the DMG, drag **Cue.app** into **Applications**, then open Cue. Before replacing an existing copy, choose **Quit Cue** from its menu. Replacing the app preserves your settings.

### Features

- **Option+Space** opens search; type directly, select with the arrow keys, press Enter to open, or Escape to dismiss.
- AppKit input and results, reused views, cached searches, and background icon loading and decoding. The panel dismisses immediately on Enter.
- Type **更新索引**, `reindex`, or `refresh apps` to rescan installed apps.
- **Command+,** opens Settings for the global shortcut, result limit, display placement, and dismissal on focus loss. Settings persist across restarts.
- System hot keys require no Accessibility permission. Version 0.1.0 has no network services, tracking, or analytics.

### Compatibility and validation

The universal build includes **arm64 and x86_64**, targeting **macOS 14 or later**. Runtime testing was performed only on **Apple silicon with macOS 26.6.2**; Intel, other macOS versions, and first installation on other machines remain unverified.

Before release, 39 Release tests, the settings persistence check, architecture and bundle-signature checks, DMG mounting, and checksum verification passed. The app copied from the DMG was also tested for search, selection, app launching, index refresh, and Settings.

This preview is **ad-hoc signed**, without Developer ID signing or Apple notarization. macOS may block its first launch; see the [System Settings instructions](https://github.com/hsiuhsiu/cue/blob/v0.1.0/docs/installation.md#首次開啟).

### Known limitations

- Menu-bar app with no Dock icon; version 0.1.0 has no automatic updates or launch-at-login feature.
- The index is built at startup; refresh it after installing or removing apps.
- Multiple displays, full-screen use, and other macOS versions need further testing.
- Performance improvements are not an end-to-end latency comparison with Raycast.

## 正體中文

Cue 是原生 macOS 應用程式啟動器，常駐選單列，以鍵盤搜尋並開啟已安裝的 App。下載目前已公開。

開啟 DMG，將 **Cue.app** 拖曳至「應用程式」，再開啟 Cue。若取代舊版本，請先從 Cue 選單列選擇 **Quit Cue**；既有設定會保留。

### 功能

- **Option+Space** 呼叫搜尋面板，直接輸入、方向鍵選取、Enter 開啟、Escape 關閉。
- 以 AppKit 處理搜尋輸入與結果列表，重用視圖、快取搜尋，並在背景載入與解碼圖示；按 Enter 後立即關閉面板。
- 輸入 **更新索引**、`reindex` 或 `refresh apps`，直接重新掃描應用程式。
- **Command+,** 開啟設定，可調整全域快捷鍵、結果數量、顯示螢幕與切換 App 時的關閉行為；設定跨重啟保存。
- 快捷鍵使用 macOS 系統 API，不需要輔助使用權限。0.1.0 版沒有網路服務、追蹤或分析功能。

### 相容性與驗證

通用版包含 **arm64 與 x86_64**，最低建置目標為 **macOS 14**。這次僅在 **Apple silicon、macOS 26.6.2** 進行執行測試；Intel、其他 macOS 版本及其他機器的首次安裝仍待驗證。

發布前已通過 39 項 Release 測試、設定保存檢查、兩種架構與完整套件簽章驗證，以及 DMG 掛載與檢查碼驗證。也已從 DMG 複製 App，實際操作搜尋、選取、開啟 App、更新索引與設定頁。

本版僅有 **ad-hoc 簽章**，沒有 Developer ID 簽章，也未經 Apple 公證。macOS 可能攔下首次開啟；請閱讀[安裝說明中的系統設定流程](https://github.com/hsiuhsiu/cue/blob/v0.1.0/docs/installation.md#首次開啟)。

### 已知限制

- 常駐選單列，沒有 Dock 圖示；0.1.0 版尚無自動更新或登入時自動啟動功能。
- 索引在啟動時建立，新增或移除 App 後需執行更新索引。
- 多螢幕、全螢幕及不同 macOS 版本的使用情境仍需更多驗證。
- 效能改進尚未構成與 Raycast 的端到端延遲比較。
