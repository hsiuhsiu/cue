# Cue 0.5.0 — Offline control and Chinese conversion / 網路控制與簡繁互轉

## English

Cue 0.5.0 adds control over network access, offline Chinese conversion for selected text, Screen Off, and clearer command icons.

- **Global network control:** open **Command+, → Network → Allow network access**. Turning it off disables both automatic and manual update checks, blocks new downloads, requests cancellation of active updater work, and closes update-offer/download-progress windows. Automatic checking appears off and locked while networking is disabled; its previous preference is remembered for when you allow networking again. Search, Clipboard History, system commands, and Chinese conversion keep working. This is Cue's own network policy, not a firewall for other apps or macOS services; already-sent or buffered network data cannot be recalled, and an installation already underway cannot be undone by this switch.
- **Defaults for your installation:** source builds start with networking **off**; the official DMG starts with it **on**. An explicit choice saved in Settings always wins, including after switching between distributions. Old automatic-update settings alone cannot enable networking in a source build. First-time source dependency downloads happen in the build tools, separately from the running app's permission.
- **Selected-text Chinese conversion:** select text in an editable field, invoke Cue, enter **`st`** for Traditional Chinese with Taiwan vocabulary or **`ts`** for Simplified Chinese with mainland China vocabulary, then press Return. Cue replaces the selection in the original app; use that app's Command+Z to undo. Both directions use bundled OpenCC dictionaries and retain full functionality with networking off. Text is never sent to a conversion service. Search **`chinese settings`** to customize the aliases; Command-comma also opens these settings when a conversion command is selected.
- **Screen Off:** search **`screen off`**, **`display off`**, or **`關閉螢幕`** to turn off the display while the Mac keeps running. Password requirements follow macOS Lock Screen settings; use the separate Lock Screen command when you want to lock the session.
- **Clearer commands and focus:** white command tiles with blue outlines distinguish clipboard, conversion, indexing, sleep, lock, and screen-off actions. Icons are prepared in the background and cached. Invoking Cue now activates its input correctly while retaining the original app for text replacement.

### Install or upgrade

[Download Cue 0.5.0](https://github.com/hsiuhsiu/cue/releases/download/v0.5.0/Cue-0.5.0-universal.dmg) · [Checksums](https://github.com/hsiuhsiu/cue/releases/download/v0.5.0/SHA256SUMS.txt)

Choose **Check for Updates… → Install and Relaunch** in Cue, or quit Cue, open the DMG, and drag **Cue.app** into **Applications**, replacing the old copy. Open the installed app; its default shortcut is **Option+Space**. Settings, clipboard history, and search learning are preserved. Updating requires a writable installed location, not the read-only DMG. You decide when to install; automatic downloads and unattended installation are disabled. Published builds normally check once a day when network access and automatic checks are both enabled.

To build your own offline-by-default copy, install full **Xcode with Swift 6 or later**, open it once, and complete its license and setup. Quit Cue, then run:

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

The first build downloads the pinned Sparkle dependency; ordinary builds use the Chinese dictionaries already in the repository. The optimized app is permanently installed at `~/Applications/Cue.app`. For later source updates, quit Cue and run `git pull --ff-only` followed by `./scripts/install-app.sh`. Existing explicit network choices are preserved. If you enable networking and install an offered update, it replaces your build with the published app. See the [source guide](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/building.md) and [network policy](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/network-policy.md).

The app is ad hoc-signed, **without Developer ID signing or Apple notarization**. Follow the app-specific [first-launch instructions](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/installation.md) if macOS blocks it. Chinese text replacement requires **Accessibility** permission for the installed copy of Cue. Rebuilding or updating can invalidate an older grant; remove the old Cue entry and add the current app if the switch appears enabled but access fails. See the [conversion guide](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/chinese-conversion.md).

Conversion requires an editor that exposes editable selected text to Accessibility. Password fields, read-only pages, unsupported editors, and selections over 256 KiB are rejected. Conversion follows dictionary rules rather than context, and pasted text may lose rich formatting. Cue restores the clipboard when it can safely confirm the replacement; other clipboard managers can observe the temporary data.

Validation covers optimized core and app-level checks, isolated network-policy/update transitions, packaging defaults, localization, and signed universal artifacts. TextEdit's `st` replacement and Undo/Redo were tested with a physical launcher shortcut during development; physical `ts` use and other editors remain unverified. System-action tests inject substitutes without sleeping, locking, or turning off the test Mac. Logout/reboot startup and a public update installation on a second Mac remain unverified. The app targets **macOS 14+**, with Apple silicon and Intel binaries; runtime verification uses **Apple silicon / macOS 27.0 / Xcode 27**.

## 正體中文

Cue 0.5.0 加入全域網路控制、針對選取文字的離線簡繁互轉、關閉螢幕，以及更清楚的指令圖示。

- **全域網路控制：**開啟 **Command+, → 網路 → 允許使用網路**。關閉後，自動與手動檢查更新都會停用，阻止新下載、要求取消進行中的更新工作，並關閉更新提示與下載進度視窗。自動檢查會顯示為關閉且無法操作，但保留原本的選擇，重新允許網路後才可恢復。搜尋、剪貼簿記錄、系統指令與簡繁轉換仍可使用。這是 Cue 自己的網路政策，不是管理其他 App 或 macOS 服務的防火牆；已送出或進入網路緩衝區的資料無法收回，也無法藉此撤銷已開始的更新安裝。
- **依安裝方式選擇預設值：**自行編譯版預設**關閉**網路，正式 DMG 預設**開啟**。曾在設定明確選擇的值優先，即使換用另一種版本也會保留。舊版的自動更新設定不會自行開啟來源版的網路。首次建置下載相依套件由開發工具進行，與執行中 App 的網路許可分開。
- **選取文字簡繁互轉：**在可編輯欄位選取文字、叫出 Cue，輸入 **`st`** 轉為正體中文與台灣用詞，或 **`ts`** 轉為簡體中文與中國大陸用詞，再按 Return。Cue 會在原 App 取代選取內容，可用原 App 的 Command+Z 復原。兩個方向都使用內附 OpenCC 詞庫，關閉網路仍保留完整功能，不會把文字送到轉換服務。搜尋 **`簡繁設定`** 可自訂別名；選到轉換指令時，Command+逗號也會開啟該功能的設定。
- **關閉螢幕：**搜尋 **`screen off`**、**`display off`** 或 **`關閉螢幕`**，讓螢幕休眠而 Mac 繼續運作。喚醒時的密碼要求依 macOS 鎖定畫面設定；若目的是鎖定工作階段，請使用獨立的「鎖定螢幕」指令。
- **更清楚的指令與焦點：**白底藍色線條的圖示區分剪貼簿、轉換、索引、睡眠、鎖定與關閉螢幕。圖示在背景產生並快取。叫出 Cue 時會正確取得輸入焦點，同時保留原 App 資訊，供文字取代使用。

### 安裝或升級

[下載 Cue 0.5.0](https://github.com/hsiuhsiu/cue/releases/download/v0.5.0/Cue-0.5.0-universal.dmg) · [檢查碼](https://github.com/hsiuhsiu/cue/releases/download/v0.5.0/SHA256SUMS.txt)

從 Cue 選擇**檢查更新⋯ → 安裝與重新啟動**；或先結束 Cue，開啟 DMG，將 **Cue.app** 拖進**應用程式**取代舊版本，再開啟已安裝的 App。預設快速鍵為 **Option+Space**。設定、剪貼簿記錄與搜尋學習資料會保留。更新需要已安裝且可寫入的位置，不能直接從唯讀 DMG 執行。安裝時間由你決定，自動下載及無人操作安裝均已停用。正式版在允許網路且開啟自動檢查時，通常每日檢查一次。

自行建置預設離線的版本，需要內含 **Swift 6 以上的完整 Xcode**，並先開啟完成授權與設定。先結束 Cue，再執行：

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

首次建置會下載固定版本的 Sparkle 相依套件；一般建置直接使用儲存庫內附的中文詞庫。最佳化 App 會固定安裝至 `~/Applications/Cue.app`。日後更新來源版時，先結束 Cue，再執行 `git pull --ff-only` 與 `./scripts/install-app.sh`。既有的明確網路選擇會保留。若允許網路並安裝 Cue 提供的更新，會換成已發布的 App。詳見[原始碼指引](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/building.md)與[網路政策](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/network-policy.md)。

App 使用 ad hoc 簽章，**沒有 Developer ID 簽署，也尚未經 Apple 公證**。若 macOS 阻擋，請依針對 Cue 的[首次開啟說明](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/installation.md)操作。跨 App 取代文字需要為目前安裝的 Cue 開啟**輔助使用**權限。重新建置或更新可能讓舊授權失效；若開關已開啟卻無法使用，請移除舊 Cue 項目，再加入目前的 App。詳見[轉換指引](https://github.com/hsiuhsiu/cue/blob/v0.5.0/docs/chinese-conversion.md)。

轉換需要編輯器透過輔助使用提供可編輯的選取文字。密碼欄位、唯讀頁面、不支援的編輯器及超過 256 KiB 的選取內容不適用。轉換採字詞規則，不理解上下文；貼入文字可能失去富文字格式。Cue 在能安全確認取代結果時會還原剪貼簿，其他剪貼簿管理程式仍可能觀察到暫存內容。

驗證包含最佳化的核心與 App 層檢查、隔離的網路政策及更新切換測試、封裝預設值、翻譯與已簽署通用版產物。開發期間已用實體啟動快速鍵，在 TextEdit 驗證 `st` 取代及復原／重做；`ts` 實體操作與其他編輯器仍未驗證。系統指令測試使用替代動作，未實際讓測試 Mac 睡眠、鎖定或關閉螢幕。登入後啟動的登出／重開機循環，以及另一台 Mac 從公開來源更新安裝，仍未驗證。App 建置目標為 **macOS 14+**，內含 Apple silicon 與 Intel 執行檔；實際執行驗證環境為 **Apple silicon／macOS 27.0／Xcode 27**。
