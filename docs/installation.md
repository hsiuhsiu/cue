# 安裝 Cue

Cue 是選單列中的 macOS 啟動器，提供 App 搜尋、即時計算、單位與幣值換算、剪貼簿記錄、離線簡繁轉換與系統指令。按下 **Option+Space** 即可開始輸入；安裝不需要 Xcode 或終端機。

## 下載

- [下載 Cue 0.8.0 通用版 DMG](https://github.com/hsiuhsiu/cue/releases/download/v0.8.0/Cue-0.8.0-universal.dmg)
- [版本說明與下載檔案](https://github.com/hsiuhsiu/cue/releases/tag/v0.8.0)

儲存庫與下載現在都已公開，不需要 GitHub 帳號。版本說明同時提供 English／正體中文。

安裝檔同時包含 Apple silicon 與 Intel 版本，最低建置目標為 macOS 14。此版本僅在 **Apple silicon、macOS 27.0** 實際執行測試；Intel 與其他 macOS 版本尚未驗證。

## 安裝與更新

1. 若 Cue 正在執行，先從選單列的 Cue 圖示選擇**結束 Cue／Quit Cue**。
2. 開啟下載的 **Cue-0.8.0-universal.dmg**。
3. 將 **Cue.app** 拖曳至 **Applications／應用程式**。若已有舊版本，選擇取代。
4. 從「應用程式」開啟 Cue，再退出掛載的 Cue 磁碟映像。

Cue 會出現在選單列，不會顯示 Dock 圖示。按下 **Option+Space**，或從選單列選擇**顯示 Cue／Show Cue**即可開啟搜尋面板。

已有 Cue 且允許使用網路、選單提供「檢查更新」時，也可直接從 App 內更新至 0.8.0。若沒有此選項，依上方步驟安裝即可，原有設定會保留。

## 從原始碼安裝

如果想自行建置、不下載 DMG，請先安裝完整 Xcode（Swift 6 以上），開啟並完成授權與首次啟動設定；升級至 Xcode 27 後若再次要求，也需先完成。結束正在執行的 Cue 後，在終端機執行：

```sh
git clone https://github.com/hsiuhsiu/cue.git
cd cue
./scripts/install-app.sh
open "$HOME/Applications/Cue.app"
```

腳本會建立最佳化的 Release 版本，安裝至使用者個人資料夾中的 **`~/Applications/Cue.app`**。不需要付費 Apple Developer 帳號、簽章金鑰或管理者權限；原有設定與剪貼簿記錄會保留。完整雙語操作說明、更新方式與其他安裝位置見[原始碼建置與安裝](building.md)。

之後更新自行建置版時，先結束 Cue，在同一份儲存庫執行 `git pull --ff-only` 與 `./scripts/install-app.sh`，再重新開啟已安裝的 App。

首次建置需要網路下載固定版本的 Sparkle 相依套件；執行中的自行建置版預設關閉網路與自動檢查更新。若曾在設定中明確選擇允許或關閉網路，會保留該選擇。

**設定 → 登入時啟動**可在登入 macOS 後自動執行 Cue，下載版與自行建置版皆可使用，首次安裝不會自動啟用。若 macOS 要求允許，按**開啟登入項目⋯**完成設定。

## 首次開啟

此版本只有 ad-hoc 簽章，尚未使用 Developer ID 簽署，也未經 Apple 公證。首次開啟時，macOS 可能顯示無法驗證開發者或無法檢查 App 的提示。

確認檔案來自上方的 Cue 版本頁面，且你信任這個版本後，可依 Apple 官方流程操作：

1. 先在「應用程式」中嘗試開啟 Cue。
2. 開啟「系統設定」中的「隱私權與安全性」，向下找到 Cue 的提示，按「強制打開」。
3. 再次出現提示時，確認要執行 Cue，再按「打開」。

以上流程依據 [Apple：在 Mac 上安全地開啟 App](https://support.apple.com/zh-tw/102445)。公司管理的 Mac 可能限制相關選項。若沒有「強制打開」或仍無法開啟，請回報提示內容；此版本尚未驗證其他機器的首次安裝。若提示指出 App 已損壞或會損壞電腦，請停止安裝並回報。

## 開始使用

| 操作 | 功能 |
| --- | --- |
| Option+Space | 顯示或關閉 Cue，這是預設快捷鍵 |
| 直接輸入 App 名稱 | 搜尋應用程式 |
| 上／下方向鍵、Enter | 選擇並開啟搜尋結果 |
| Command+1–9 | 立即執行對應編號的結果；在剪貼簿頁會拷貝該筆記錄並關閉 Cue |
| Escape | 關閉搜尋面板 |
| Cue 中按 Command+, | 開啟設定 |

主視窗剛開啟時只有空白輸入欄；開始打字後才會顯示結果。最多顯示九筆，不使用捲軸；若沒有看到想找的項目，請輸入更精確的名稱。字體較大、視窗高度依結果數量調整，並使用呼應圖示的藍色色調。

設定頁可以更改全域快速鍵、顯示螢幕、切換 App 時是否隱藏面板、介面語言、登入時啟動、網路存取，以及更新檢查。按 **Command+,** 會將設定視窗帶到最前面並取得鍵盤焦點。設定會立即保存；除了語言需重新開啟 Cue，其餘設定立即生效。若預設快速鍵被其他 App 使用，請從 Cue 選單列的**設定⋯／Settings…** 更換。

安裝或移除其他 App 後，在 Cue 輸入**更新索引**、`reindex` 或 `refresh apps`，選擇**更新應用程式索引／Update App Index** 並按 Enter，即可在背景重新掃描。

### 依使用習慣排序

Cue 會記住成功開啟的 App 或指令。同一文字符合程度內，優先考慮相同關鍵字的選擇，再參考使用頻率與近期使用；完全符合的 App 仍排在較弱的 App 符合結果前面。相同關鍵字的成功選擇也能讓 App 超過碰巧符合的內建指令，例如 `it` 的 iTerm2；明確設定的完整指令別名仍優先。資料只存本機，打字、取消或失敗操作不會記錄，背景學習完成也不會讓眼前的列表突然跳動。詳見[搜尋習慣與效能說明](performance-adaptive-search.md)。

### 即時計算

直接輸入 `1+2*3`、`(12+8)/4` 或 `2^10`，答案會顯示在第一列。選取答案後按 **Return**，或按 **Command+1**，即可只拷貝數值並收起 Cue，再到目標 App 按 **Command+V** 貼上。次方可用 `^` 或 `**`，也支援負指數與小數指數；精確值標示 `=`，近似值標示 `≈`。計算完全離線，不會自動貼上，也不會把算式或結果加入搜尋學習。語法、優先順序與限制見[計算機說明](calculator.md)。

### 單位與幣值換算

輸入 `10m`、`5坪` 或 `100USD`，即可顯示最多三種常用換算；用 `10m to ft` 或 `100USD to TWD` 可指定目標。選取結果後按 **Return** 或對應的 **Command+數字**，只拷貝數值並收起 Cue。一般單位涵蓋長度、面積（含台灣的坪）、質量、體積、溫度、時間與速度，完全離線。

幣值換算需要開啟**設定 → 網路 → 允許 Cue 自行連網**，使用每日參考匯率並顯示來源與資料時間，無需 API 金鑰。Cue 在背景下載固定匯率表，金額及查詢文字不會傳出；關閉網路會取消匯率工作，快取的幣值答案也會隱藏。匯率不是即時行情或銀行報價；過期資料不會當成目前答案。詳見[單位與幣值換算說明](unit-conversion.md)。

### 剪貼簿記錄

輸入 `clipboard` 或「剪貼簿」即可開啟記錄頁。功能**預設關閉**；選擇**啟用剪貼簿記錄**後才會記錄新拷貝的文字與連結，不會匯入原本已在系統剪貼簿中的內容。

每筆記錄顯示日期時間；按 Enter 或 Command+1–9 拷貝，再到目的 App 按 Command+V 貼上。搜尋欄空白時可按 Delete 刪除所選記錄；有搜尋文字時，使用**刪除**按鈕或 Command+Delete。剪貼簿頁的齒輪與 Command+, 會開啟自己的設定，可設定記錄開關與保留時間，預設為七天。

記錄只存於本機，以可讀文字儲存，最多 500 筆或 4 MiB；已知的敏感剪貼簿標記會被略過，但無法辨識所有敏感內容。搜尋涵蓋全部記錄，每次最多顯示九筆，顯示限制不會刪除較舊內容。詳見[剪貼簿記錄說明](clipboard.md)。

### 簡繁互轉

在其他 App 的可編輯欄位選取文字，叫出 Cue 後輸入 `st` 轉為正體中文與台灣用詞，或 `ts` 轉為簡體中文與中國大陸用詞，再按 Return 取代選取內容。可在原 App 用 Command+Z 復原。輸入「簡繁設定」可自訂別名；跨 App 取代需要允許 macOS「輔助使用」權限。轉換使用內附詞庫，完全離線，首次使用也不需下載。支援範圍與授權方式見[簡繁互轉說明](chinese-conversion.md)。

### 睡眠、鎖定與關閉螢幕

輸入 `sleep`／「睡眠」，或 `lock`／「鎖定」，按 Enter 或對應的 Command+數字即可要求 Mac 睡眠或鎖定螢幕。兩者都不會登出或關閉其他 App。此版已驗證搜尋、鍵盤與錯誤處理，未在測試中實際執行睡眠或鎖定。鎖定功能使用 macOS 私有服務，未來系統更新可能影響相容性；詳見[系統指令說明](system-actions.md)。

`screen off`／`display off`／「關閉螢幕」會要求顯示器立即睡眠，Mac 繼續運作。喚醒是否需要密碼依 macOS 設定；需要鎖定電腦時，請使用「鎖定螢幕」。實際關閉顯示器的狀態切換尚未經人工驗證。

## 介面語言

Cue 支援英文與正體中文，包含所有設定、選單、搜尋提示，以及 Cue 的狀態與錯誤訊息。預設為**跟隨系統／Follow System**，依 macOS 的語言偏好選擇介面。

到**設定 → 語言 → App 語言**（**Settings → Language → App language**）可改為 **English** 或**正體中文**。選擇後退出並重新開啟 Cue，語言變更才會生效；也可隨時改回跟隨系統。Cue 的名稱不變，已安裝的應用程式名稱仍依 macOS 顯示，不受 Cue 的語言選項影響。

## App 內更新

**設定 → 網路 → 允許使用網路**管理 Cue 的網路功能。首次安裝正式 DMG 預設開啟網路與自動檢查更新，約每天在背景檢查一次；自行建置版預設關閉，缺少建置資料也視為關閉。明確儲存的網路選擇與既有自動檢查偏好優先，不會因更新或重新安裝而重設。找到新版時，選單列圖示會加上小圓點，選單中也會顯示版本，不會搶走搜尋框或其他 App 的焦點。

從 Cue 選單列選擇**檢查更新⋯／Check for Updates…**，或在主啟動器按 **Command+, → 更新／Updates**，即可手動檢查、查看更新。選擇下載後，依更新視窗的安裝並重新啟動提示完成（英文介面為 **Install and Relaunch**）。請先把 Cue 安裝至「應用程式」等可寫入的位置再更新；直接從唯讀 DMG 執行無法自我更新，安裝需要額外權限時 macOS 可能要求授權。

允許網路時，設定中的**自動檢查更新／Automatically check for updates** 可隨時關閉，手動檢查仍可使用。若關閉**允許使用網路**，手動、自動檢查及下載都會停用，幣值答案也會隱藏；自動檢查開關顯示關閉且無法操作，但會記住原本偏好，重新允許網路後可恢復。Cue 不會自動替你安裝或重啟，也不會傳送使用行為分析或系統資訊；更新檢查與下載會連線至 GitHub。

關閉網路不影響 App 搜尋、計算機、一般單位換算、剪貼簿記錄、系統指令或完整的簡繁轉換。適用範圍與進行中更新的取消行為，見[網路存取說明](network-policy.md)。

## 重新安裝與限制

更新或重新安裝時，依照上方步驟退出 Cue、取代「應用程式」中的 Cue.app，再重新開啟。設定存放在 App 外，單純取代 Cue.app 會保留既有快捷鍵與其他設定。macOS 在更新後可能再次要求允許開啟，請參照[首次開啟](#首次開啟)流程。

已安裝的 Cue.app 會保留在磁碟上，不受重開機或清除儲存庫建置產物影響。重新登入後可從「應用程式」開啟，也可啟用「登入時啟動」讓 Cue 自動執行。應用程式索引會在 Cue 啟動時建立，也可以手動更新。

版本頁同時提供 **SHA256SUMS.txt**，供需要核對下載檔案完整性的人使用。App 內更新另外以 Cue 內建的公開金鑰驗證更新檔與資訊；這些措施都不代表 Apple 簽署或公證。
