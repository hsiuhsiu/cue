由來

怎麼會有 Cue？

習慣用這些工具，
後來就自己做了一個。

我一路從 Quicksilver 用到 Alfred，再到 Raycast。這些工具的功能越來越多，也越來越複雜，但用來用去，自己常用的其實就那幾個。

加上自己也在意隱私，就想說，既然要的東西很明確，不如自己做一個，把需要的功能做好，速度能多快就多快。現在有 AI 幫忙，自己動手的成本也沒那麼高了，所以就做了 Cue。

原始碼也公開了。有興趣可以直接拿來用，覺得哪裡不順手、想加點什麼或拿掉什麼，也可以 fork 一份，自己改、自己 build，做一個你用起來順手的 Cue。

每天用得到的

幾件小事，
順手就能做好。

macOS 原生、鍵盤優先。
支援 English 與正體中文。

⌘

找到，然後打開。

搜尋 App、設定自己的縮寫，讓排序慢慢記住你的習慣。輸入 f 報告，也能透過 Spotlight 找檔名。

⌥ Space 接著開始打字
⎘

剛剛拷貝了什麼？

找回拷貝過的文字與連結，刪掉特定記錄，自己決定保留多久。開啟記錄功能之後，才會開始儲存。

clipboard 文字與連結記錄
繁

處理一下文字。

直接轉換選取文字的簡繁與台灣／中國大陸用詞、清理連結裡的追蹤參數，或找個 Emoji。這些都在本機完成。

繁 / 简 離線簡繁轉換
=

順手算一下。

輸入算式，結果就會出現。單位換算也包含台灣的坪；允許 Cue 連網時，還能查詢幣值換算。

2^10 1,024
?

查一下，或問一下。

用指定的瀏覽器 Google 搜尋，或接自己的 OpenAI API key，快速問答與翻譯。GPT 需要連網，API 費用另計。

⌘ K 選擇怎麼處理這段文字
⊞

把視窗放好。

用鍵盤調整大小、跨螢幕移動、置中或還原。儲存自己的視窗配置，也能把設定帶到另一台 Mac。

⌥ M 叫出視窗控制
自己的 Mac，自己決定。

本機工具離線就能用。更新、GPT 與匯率需要 Cue 連網，由你決定是否允許；瀏覽器搜尋則只在你明確執行時送出。視窗調整與選取文字取代，需要 macOS 輔助使用權限。

一路走來

需要什麼，
就慢慢加進來。

幾個版本，
幾個重要的轉折。

  1. 0.1–0.2

    先從啟動器開始。

    原生 App 搜尋、鍵盤操作、App 內更新，以及正體中文介面。

  2. 0.3–0.4

    更貼近自己的習慣。

    加入剪貼簿記錄、系統指令，以及會記住常用選擇的搜尋排序。

  3. 0.5–0.6

    把文字小工具放在一起。

    離線簡繁轉換、網路控制、Google 搜尋、連結清理與 Emoji。

  4. 0.7–0.9

    快速得到一個答案。

    即時計算、單位與幣值換算、GPT 問答與翻譯，還有 App 搜尋別名。

  5. 1.0

    日常會用到的，大致到齊了。

    加入視窗控制、檔名搜尋與設定備份，再把操作反應好好整理了一輪。
