由來

怎麼會有 Cue？

習慣用這些工具，
後來就自己做了一個。

我一路從 Quicksilver 用到 Alfred，再到 Raycast。後來開始在意，自己其實沒辦法完全掌握這些工具在做什麼，也就很難完全放心。回頭看看，才發現那麼多功能，自己用到的其實只有一小部分。

現在有 AI agent 幫忙，自己做一個的成本低了很多，就想說乾脆試試看。程式碼握在自己手上，只做需要的功能，就能多花點心力把速度磨到最好；操作方式也可以完全照自己的習慣，不用考慮怎麼讓所有人都滿意。Cue 就這樣做出來了。

歡迎 fork，也很歡迎帶著自己的 agent 來改。想加什麼、拿掉什麼，都隨你。希望這個起點能幫你省一點 token，少走一些從零開始的路。

如果只是想找個輕巧的開源啟動器，不想自己動手改，直接拿來用也很好。

每天用得到的

幾件小事，
順手就能做好。

macOS 原生、鍵盤優先。
支援 English 與正體中文。

⌘

找到，然後打開。

搜尋 App、設定自己的縮寫，讓排序慢慢記住你的習慣。輸入 f 報告，也能透過 Spotlight 找檔名。

⌥ Space 接著開始打字
⎘

剛剛拷貝了什麼？

找回拷貝過的文字與連結，刪掉特定記錄，自己決定保留多久。開啟記錄功能之後，才會開始儲存。

clipboard 文字與連結記錄
繁

處理一下文字。

直接轉換選取文字的簡繁與台灣／中國大陸用詞、清理連結裡的追蹤參數，或找個 Emoji。這些都在本機完成。

繁 / 简 離線簡繁轉換
=

順手算一下。

輸入算式，結果就會出現。單位換算也包含台灣的坪；允許 Cue 連網時，還能查詢幣值換算。

2^10 1,024
?

查一下，或問一下。

用指定的瀏覽器 Google 搜尋，或接自己的 OpenAI API key，快速問答與翻譯。GPT 需要連網，API 費用另計。

⌘ K 選擇怎麼處理這段文字
⊞

把視窗放好。

用鍵盤調整大小、跨螢幕移動、置中或還原。儲存自己的視窗配置，也能把設定帶到另一台 Mac。

⌥ M 叫出視窗控制
自己的 Mac，自己決定。

本機工具離線就能用。更新、GPT 與匯率需要 Cue 連網，由你決定是否允許；瀏覽器搜尋則只在你明確執行時送出。視窗調整與選取文字取代，需要 macOS 輔助使用權限。
